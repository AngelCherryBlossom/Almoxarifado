
# REQUISITOS FUNCIONAIS
 +  [RF1]: O sistema deve permitir o registro de entrada de novos materiais e a baixa de materiais.
 +  [RF2]: O sistema deve permitir que os colaboradores autorizados criem requisições de materiais.
 +  [RF3]: O sistema deve emitir notificações automáticas por e-mail para o administrador sempre que o saldo de um item que esteja com estoque baixo.

# REQUISITO NÃO-FUNCIONAL

+ [RNF1]: O sistema deve garantiR que apenas usuários administradores aprovar requisições de alto valor.
+ [RNF2]: O sistema deve ser capaz de processar e atualizar a consulta de saldo de um item em um tempo máximo de 2 segundos
+ [RNF3]: O sistema de almoxarifado deve estar disponível para os usuários pelo menos 99,5% do tempo durante o horário comercial
